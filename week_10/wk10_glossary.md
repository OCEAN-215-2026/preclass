# Week 10 glossary

## Numpy function

+ `np.interp()`: numpy function for performing interpolation in one dimension


## Scipy functions

+ `scipy.interpolate.RegularGridInterpolator()`: scipy function for performing interpolation in higher dimensions when the available data is defined on a regular grid.

+ `scipy.interpolate.LinearNDInterpolator()`: scipy function for performing linear interpolation in higher dimensions when the available data is unstructured.


## Python syntax features

+ `def ...(...):` : the starting line of a function definition
